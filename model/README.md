* panAsp\_v3.xlsx: the pan-oryzae GEM in xlsx format
* panAsp\_v3.xml: the pan-oryzae GEM in xml format
* panAsp\_ensemble\_187\_strains.pickle: the GEM of all 187 strains in this study in pickle format. The object generated from reading this file into a python environment will be an ensemble model, i.e., a set of cobrapy objects combined such that downstream analyses, like FBA, can be performed efficiently.
* panAsp\_gemList\_187\_strains.pickle: the GEM of all 187 strains in this study in pickle format. The object generated from reading this file into a python environment will be a list of cobrapy models. Dowsntream  analyses, like FBA, can be performed on each element of this list individually.
